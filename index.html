Setup sekali sahaja

  1. Settings › About phone › tekan Build number 7 kali untuk buka Developer options.
  2. Developer options › hidupkan Wireless debugging. Phone kena sambung WiFi.
  3. Pasang Shizuku dari Play Store › Start via Wireless debugging › ikut langkah pairing.
  4. Pasang aShell dari Play Store › benarkan akses Shizuku.
  5. Tandakan tugas di bawah › tekan Copy semua › paste dalam aShell › Enter.
Mula dengan bahagian Laju dan Storage dulu sebab dua-dua tu paling selamat. Untuk Bloatware, buang sikit-sikit dan simpan command Pulih.

Bloatware

Pilih jenama phone. Nama package boleh berbeza ikut model. Kalau package tak wujud, aShell cuma tunjuk "not installed" dan tiada apa yang rosak.

Jalankan pm list packages dalam aShell, copy hasilnya, paste kat sini. Senarai akan tunjuk app yang betul-betul ada sahaja.

Pulih (simpan ni)

Kalau ada fungsi hilang lepas buang app, paste command ni dalam aShell untuk pulihkan app yang Bob tanda, dan set animasi balik ke asal.
