Nak aShell percuma? Ambil dari F-Droid. App sama, cuma kena benarkan "Install unknown apps" untuk browser.

  1. Download Shizuku dan aShell guna butang atas.
  2. Settings › About phone › tekan Build number 7 kali untuk buka Developer options.
  3. Developer options › hidupkan Wireless debugging. Phone kena sambung WiFi.
  4. Buka Shizuku › Start via Wireless debugging › ikut langkah pairing.
  5. Buka aShell › benarkan akses Shizuku. Siap, teruskan ke Langkah 2.

03Bloatware

Pilih jenama phone. Nama package boleh berbeza ikut model. Kalau package tak wujud, aShell cuma tunjuk "not installed" dan tiada apa yang rosak.

Jalankan pm list packages dalam aShell, copy hasilnya, paste kat sini. Senarai akan tunjuk app yang betul-betul ada sahaja.

04Pulih (simpan ni)

Kalau ada fungsi hilang lepas buang app, paste command ni dalam aShell untuk pulihkan app yang Bob tanda, dan set animasi balik ke asal.
